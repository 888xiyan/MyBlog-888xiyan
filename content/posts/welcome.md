这是博客的第一篇文章。站点基于 **Hugo Extended** 与 **PaperMod** 主题构建，支持文章、标签、归档、全文搜索和深浅色模式。

## 开始写作

在项目根目录执行：

```bash
./bin/hugo new content posts/文章名.md
```

编辑文章后，本地预览：

```bash
./bin/hugo server --buildDrafts
```
